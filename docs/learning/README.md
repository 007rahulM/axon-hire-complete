## The Senior Engineer's Mindset

Before you write a single line of code, a senior engineer asks:

1. **What can go wrong?** — security risks, crashes, edge cases
2. **What happens at scale?** — would this work with 1000x more data/users?
3. **Can I understand this in 6 months?** — readability, documentation, comments
4. **Is there an existing tool for this?** — don't reinvent what already exists
5. **What's the simplest thing that works?** — avoid over-engineering

You don't need to know everything. You need to ask the right questions.
