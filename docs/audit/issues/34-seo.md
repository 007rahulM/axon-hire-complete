## 🔍 Understanding the SEO Problem

### How Search Engine Crawlers Work

1. Google's crawler (Googlebot) requests your page
2. Receives the HTML from your server
3. Reads the `<title>`, `<meta description>`, `<og:*>` tags
4. For SPAs (React apps): the initial HTML is empty. JavaScript runs in the browser to render content.
5. Googlebot can execute JavaScript — BUT it processes it asynchronously, days later
6. Job listings posted today won't be indexed for possibly a week

### Two Parts of SEO for a React SPA

**Part 1: Meta Tags (Quick Win)** — proper title, description, og:image for each page  
**Part 2: Server-Side Rendering** — serve actual HTML content so Googlebot sees jobs immediately

For Branch 6, implement Part 1. Part 2 (switching to Next.js or adding SSR) is a larger architectural change.

### Individual Job Page

When you have individual job pages at `/jobs/:id`, add dynamic meta:

```jsx
export default function JobDetail() {
  const { job } = useJob(); // Fetch the job data
  
  return (
    <>
      <Helmet>
        <title>{job.title} at {job.company} | Axon Hire</title>
        <meta name="description" content={`${job.title} - ${job.location} - ${job.type}. ${job.description?.substring(0, 150)}...`} />
        <meta property="og:title" content={`${job.title} at ${job.company}`} />
        <meta property="og:description" content={job.description?.substring(0, 200)} />
        <meta property="og:type" content="job_listing" />
        <meta property="og:url" content={`https://axon-hire.com/jobs/${job._id}`} />
        {/* Structured data for job listings — Google shows rich results */}
        <script type="application/ld+json">{JSON.stringify({
          "@context": "https://schema.org/",
          "@type": "JobPosting",
          "title": job.title,
          "description": job.description,
          "identifier": { "@type": "PropertyValue", "name": job.company, "value": job._id },
          "datePosted": job.createdAt,
          "employmentType": job.type,
          "hiringOrganization": { "@type": "Organization", "name": job.company },
          "jobLocation": { "@type": "Place", "address": { "@type": "PostalAddress", "addressLocality": job.location } },
          "baseSalary": { "@type": "MonetaryAmount", "currency": "INR", "value": job.salary },
          "validThrough": job.deadline,
        })}</script>
      </Helmet>
      {/* ...rest of component */}
    </>
  );
}
```

The `application/ld+json` structured data is the Google Jobs integration — when properly formatted, your job listings appear in Google's dedicated job search feature with salary, location, and apply button.

### What is an og:image?

The image shown when someone shares your link on Twitter/LinkedIn/WhatsApp. Without it, social shares show a blank preview. Create a 1200×630px image with your logo and tagline. Save as `public/og-image.png`.

## 🛠 Part 2: Google Search Console Setup (Manual Steps)

Even with Part 1, you need to tell Google your site exists.

1. Go to https://search.google.com/search-console
2. Click **Add Property** → enter your domain (`axon-hire.com`)
3. Verify ownership: choose "HTML file" → download the file → place it in `frontend/public/`
4. Click **Verify**
5. Go to **Sitemaps** → add `https://axon-hire.com/sitemap.xml`
6. Generate a sitemap (see below)

### Generate a Sitemap

A sitemap tells Google every URL on your site:

```js
// backend/routes/sitemapRoute.js (add to server)
router.get("/sitemap.xml", async (req, res) => {
  const jobs = await Job.find({ isOpen: true }, "_id updatedAt").lean();
  
  const urls = [
    `<url><loc>https://axon-hire.com/</loc><changefreq>weekly</changefreq><priority>1.0</priority></url>`,
    `<url><loc>https://axon-hire.com/jobs</loc><changefreq>hourly</changefreq><priority>0.9</priority></url>`,
    ...jobs.map(job => 
      `<url><loc>https://axon-hire.com/jobs/${job._id}</loc><lastmod>${new Date(job.updatedAt).toISOString().split("T")[0]}</lastmod><priority>0.7</priority></url>`
    ),
  ];
  
  res.setHeader("Content-Type", "application/xml");
  res.send(`<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
${urls.join("\n")}
</urlset>`);
});
```

## ❓ Common Questions

**Q: Will meta tags fix the React SPA crawlability problem?**  
A: Meta tags help, but the content (job descriptions) still requires JavaScript to render. For full SEO, you need SSR or pre-rendering. Next.js migration is the proper solution (Branch 7 or beyond).

**Q: What is the Google Jobs integration?**  
A: When your job listings have proper `JobPosting` structured data, they appear in Google's job search feature — separate from regular search results. This can drive significant organic traffic for a job board.

**Q: What's a canonical URL?**  
A: `<link rel="canonical" href="https://axon-hire.com/jobs" />` tells Google "this is the official URL for this content." It prevents duplicate content penalties when the same page is accessible via different URLs.

## 🎓 What You Learned

- React SPAs are client-rendered — Google's crawler sees empty HTML by default
- `react-helmet-async` lets you dynamically set `<title>`, `<meta>`, and `<og:*>` tags per page
- `application/ld+json` structured data for `JobPosting` enables the Google Jobs rich result
- Google Search Console is how you submit your site and monitor crawl status
- A sitemap tells Google all your URLs — especially important for dynamically generated pages
- Full SEO for React requires SSR (Next.js) — meta tags are a necessary but partial solution
